# Impeccable Design Context

## Design Context

### Users
Public-facing tool — anyone on the internet may discover and use this to generate secure diceware passphrases. Users arrive with a specific job: get a strong, memorable password quickly. They may be non-technical and unfamiliar with passphrase concepts. Trust must be established instantly through visual design since there's no brand recognition to lean on.

### Brand Personality
**Bold, modern, trustworthy.** The interface should feel like a contemporary startup product — visually striking and confident — while still communicating the security and reliability users need from a password tool. Three words: **bold, credible, sharp.**

### Aesthetic Direction
- **Dark mode with accent color** — dark base palette with a vibrant, distinctive accent that gives the app personality and draws the eye to key actions.
- **Fresh palette** — move away from the current muted purple-blue/teal. Choose a bold, high-contrast accent (e.g., electric green, vivid cyan, warm amber, or hot coral) against deep, near-black backgrounds.
- **Anti-references:** Generic MUI defaults, bland corporate dashboards, anything that looks like an un-styled framework demo.
- **References:** The visual confidence of Linear, the dark-mode elegance of Raycast, the bold simplicity of Vercel's design language.
- **Typography:** Roboto is already loaded — use its weight range (300–700) more aggressively. Consider a monospace or display font for the generated passphrase to make it feel distinct.

### Design Principles
1. **Instant trust** — The design must communicate security and competence within the first second. No cheap gradients, no stock-photo energy.
2. **One job, done well** — Strip away anything that doesn't serve passphrase generation. Every pixel earns its place.
3. **Bold, not loud** — Use contrast, typography scale, and whitespace to create impact. Avoid decoration for decoration's sake.
4. **Accessible by default** — WCAG AA contrast ratios on all text. Visible focus states. Reduced-motion support. The dark mode CSS framework already includes `prefers-reduced-motion` — carry this forward.
5. **Copy-first interaction** — The generated passphrase and the copy action are the hero. Everything else supports them.
